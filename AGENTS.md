# Contest facts (kickoff FAQ)

Источник: первая установочная встреча. Без воды — только зафиксированные ответы.

## Обязательное

- **openJiuwen обязателен.**
- Модели только через proxy: `qwen3.8-27b`, `qwen3.6-35b-a3b` (и их `-noreason` варианты в рамках доступа).
- Версия openJiuwen — **последняя с официального сайта**.
- Агентов можно сколько угодно и каких угодно.
- Интернета нет, только API модели.
- Локальные нейросети запрещены регламентом; классика (регрессия/бустинг) — ок.
- На оценке запуск с **фиксированной моделью**; свой код/веса/данные — если лицензия позволяет.
- AgentForge-harness — можно.

## Задачи и ответы

- Типы финала = 4 типа из примеров; сложность/структура похожи.
- В `task.json` явно есть `task_type` и `reward` (агент видит баллы заранее).
- Поле `expected` в финале **уберут**; остальные поля примеров остаются.
- Ответ: файл `answer.txt` **рядом с `task.json`** (не внутри `workspace/`).
- Coding: проверяются изменённые исходники + сдача ответа как принято.
- Невыполнимая задача = нельзя **точно** решить при имеющихся данных.
- За нерешаемую: **не создавать** `answer.txt`.
- За пропуск нерешаемой **баллы не дают** (очки только за верно решённые).

## Бюджет

- Ориентир: **100K** output-token units.
- Передаётся в env: `BUDGET=100000` (пример).
- При превышении LLM перестаёт отвечать.
- Оставшийся бюджет **прокси не сообщает** — учитывать расход самим.
- Детерминированно без LLM решать можно (хоть все задачи).

## Оценка / данные / наблюдения

- Готовых трасс и размеченного обучающего набора от организаторов **не будет** — тренировочный набор собираем сами.
- Метрики оценки оценки токенов (MAE, относительная ошибка, штраф за недооценку, точки замера) — выложат на сайт на следующей неделе после встречи.
- Наблюдения: любые, что соберёте локально / через API (история, tools, usage, workflow, compression events…).
- Фраза про «предсказать вычисления до запуска»: для оценки дадут **новые** запросы; предсказывать нужно **до** их запуска.
